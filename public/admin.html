            معلومات الورشة

            هاي النصوص بتطلع على صفحة الورشة، والعنوان وعدد الساعات بيطلعوا كمان على الشهادة.

            فاضي = بتطلع فوراً لما تحفظها «منشورة». إذا حطيت موعد، بتضل مخفية ومسكّرة لحد هاد الوقت، وبعدها بتطلع على /workshop وبيفتح التسجيل لحاله.

            اللقاء الأونلاين وتسجيل الحضور

            بيوصل للمسجّل بس بعد ما يتسجّل حضوره. بينحفظ مع «احفظ معلومات الورشة».

            بيوم الورشة نفسه (التاريخ فوق). برّا هالوقت ما حدا بيقدر يسجّل حضوره أو ياخد رابط اللقاء. إذا تركتهم فاضيين: مفتوح يوم الورشة كله.

            انشره بالجروب بدل رابط زوم/ميت. اللي بيفتحه بيدخل ببطاقته أو برقم واتسابه، فبيتسجّل حضوره «حضر» وبعدين بيتحوّل على اللقاء. الدخول بيشتغل يوم الورشة بس (حسب التاريخ فوق).

            محتوى الورشة (شو رح نغطي)

                                Claude Code بيقرأ ويعدّل بيانات الموقع بحساب الأدمن تبعك. ما في حذف أبداً، وبيشتغل على جهازك بس.

                                1. نزّل المشروع
                                  git clone https://github.com/EngHamzaAboJarad/beit-lahia-tech
                                2. ثبّت وسجّل دخول الأدمن
                                  cd beit-lahia-tech/mcp
                                  npm install
                                  npm run login
                                  كلمة السر بتنكتب مخفية وما بتنحفظ، بس بيتخزّن توكن التجديد على جهازك.
                                3. افتح Claude Code بمجلد المشروع ووافق على سيرفر beit-lahia. أو اربطه بأي مجلد بهاد الأمر (بدّل المسار):
                                  claude mcp add beit-lahia -- node /path/to/beit-lahia-tech/mcp/server.mjs
                                إرسال الشهادة بالواتساب
